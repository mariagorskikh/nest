# ResonanceBFT — real-town evidence (actual agents, real LLMs)

_Generated 2026-07-01 12:28:04 PDT. Opinion question: “Should our team adopt trunk-based development?”. 5 scenarios × 4 tiers × 3 reps = 60 town runs._

Each run drives the **real committed scenario YAML through the framework `ScenarioRunner`** — leader proposes, followers seal + reply over the in-memory transport, the leader resolves the n−f quorum and broadcasts the Outcome. The only injection is that each honest agent's opinion is generated by a real LLM (lowest tier, key-free CLI). Faults (silent / byzantine / partition) are the scenarios' own. **The deterministic fault behaviour matches the scenario's design regardless of which model wrote the opinions** — that is the point: the LLM informs perception, the deterministic BFT core owns the decision.

> **Honest read of the `expected` column.** It is the scenario's *design intent*, not a per-run guarantee. The **safety-relevant** behaviour is deterministic across all models: silent/byzantine agents never *block* the n−f quorum, tampered records are always excluded (`tampered=2`), and the partition **never** commits (12/12 no-commit). But a *commit* also requires the present agents' opinions to cohere above the `0.60` threshold, so a few real-LLM runs abort on low coherence even though the quorum was available — these are **semantic-coherence aborts, not liveness failures from the fault**. Observed commit rates here: genuine 11/12 (1 CLI error), **silent-crash 10/12** (the 2 no-commits are coherence aborts), byzantine 12/12, bag-of-words 12/12, partition 0/12 (correct). The floor-liveness claim is precisely "the fault does not remove the quorum," which every run upholds.

## Findings

- **The deterministic core is model-agnostic.** Across claude, codex and agy, every scenario with quorum slack reached its designed outcome on every rep: byzantine commits `tampered=2`, partition never commits, bag-of-words commits. The edge model changes the *opinions* and the audit's `consensus_type`, never the *decision rule*.
- **Quorum-floor liveness is opinion-sensitive (silent crash (2 of 7)).** When exactly `n−f` agents respond (zero slack — silent-crash: 7 agents, 2 silent → 5 respond, quorum_needed=5), a *coherent* quorum needs all 5 within threshold. With genuinely divergent real opinions one semantic outlier can prevent that, so the round safely does **not** commit — the same scenario always commits under the scripted mock (identical stances) and under tiers/reps whose opinions happened to cluster. This is correct safety (never commit an incoherent quorum), and a liveness nuance real-LLM testing surfaced that the mock masks. Scenarios with slack (byzantine +1, bag-of-words +2) absorb the outlier and commit every time.

## Honest notes

- **Real agents, real transport.** Every row is a full ScenarioRunner town run (propose → participate → resolve → commit over the message bus), the same path the e2e suite asserts on — not a direct protocol call.
- **Submission-safe.** The opinions hook defaults off; with no `opinions` config the scenario is byte-for-byte the shipped scripted behavior. This harness is `live`-marked and excluded from CI, so it never gates the plugin.

## Models, metrics & configuration

Every real tier is a **key-free subscription CLI**: it drops the metered API-key env var so the
interactive login drives the model, runs each call in an isolated temp cwd, and retries 3× on a
transient failure. The opinion prompt is `persona (name / angle / lean) + the question → one
sentence`. Lowest thinking tier / smallest model each — the deterministic core needs no frontier
model.

### Town configuration

Real `ScenarioRunner` stack (in-memory transport, `did_key` identity, `score_average` trust,
`resonance_bft` coordination); semantic-axis embedding `demo` (deterministic stance bag-of-words);
opinions injected via the scenario's **default-off** `opinions` hook. The commit itself uses the
protocol's fixed threshold `0.60` and axis weights (sem `.25` / aff `.20` / rel `.25` / epi `.15` /
beh `.15`) over a coordinate-wise trimmed-mean centroid (trim = the configured fault bound `f = ⌊(n−1)/3⌋`) — **independent of which
model wrote the opinions**. That independence is the whole point: the model informs *perception*,
the deterministic BFT core owns the *decision*.
